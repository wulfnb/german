# Regionale Varianten des Deutschen

Deutsch wird in verschiedenen Regionen unterschiedlich gesprochen.

## Dialekte
- [Bayerisch](bairisch.md)
- [Schwäbisch](schwaebisch.md)
- Berlinerisch
- Kölsch
- Sächsisch

## Regionale Besonderheiten
- Unterschiedliche Begrüßungen
- Regionale Spezialitäten
- Lokale Traditionen
- Wortschatz-Variationen

## Standarddeutsch vs. Dialekt
In offiziellen Situationen wird Standarddeutsch verwendet, im privaten Bereich oft Dialekt.
